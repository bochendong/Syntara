### 12. Euler 方法：从当前点沿切线走一步

- 类型：slide
- 页面角色：concept
- 内容结构：math
- 讲解目标：能够用 Euler 方法从初值出发逐步近似解曲线。
- 页面要点：
  - 微分方程：$y'=F(x,y)$，当前点：$(x_n,y_n)$，步长：$h$
  - Euler 更新：$x_{n+1}=x_n+h$
  - Euler 更新：$y_{n+1}=y_n+hF(x_n,y_n)$
  - 例：$y'=x+y$，$y(0)=1$，$h=0.5$；第一步 $y_1=1+0.5(0+1)=1.5$
  - 第二步：$x_1=0.5$，$y_2=1.5+0.5(0.5+1.5)=2.5$
- 例题配置：
  - 题目：Use Euler's method for $y'=x+y$, $y(0)=1$, step size $h=0.5$, to approximate $y(1)$.
  - 已知：$y'=x+y$；$y(0)=1$；$h=0.5$
  - 目标：用两步 Euler 方法近似 $y(1)$
  - 解题计划：从 $(x_0,y_0)=(0,1)$ 出发 -> 每一步计算当前斜率 $F(x_n,y_n)$ -> 使用 $y_{n+1}=y_n+hF(x_n,y_n)$
  - 走读步骤：第 0 步：$(x_0,y_0)=(0,1)$，斜率 $F(0,1)=1$ -> $x_1=0.5$，$y_1=1+0.5\cdot1=1.5$ -> 第 1 步：$(x_1,y_1)=(0.5,1.5)$，斜率 $F(0.5,1.5)=2$ -> $x_2=1$，$y_2=1.5+0.5\cdot2=2.5$ -> 所以 Euler 近似给出 $y(1)\approx2.5$
  - 易错点：一直使用初始斜率，不更新斜率；更新了 $y$ 却忘记更新 $x$；把步长 $h$ 漏乘到斜率上
  - 最终答案：$y(1)\approx2.5$

### 13. Euler 高估还是低估：看凹向，而不是只看斜率正负

- 类型：slide
- 页面角色：example
- 内容结构：math
- 讲解目标：能够用解曲线的凹向判断 Euler 方法的高估或低估方向。
- 页面要点：
  - 模型：$\dfrac{dN}{dt}=N\left(\dfrac{N}{6}-1\right)\left(1-\dfrac{N}{20}\right)$，初值 $N(0)=7$
  - 题目：用步长 $\Delta t=0.5$ 的 Euler 方法估计 $t=2$ 时的数量，是高估还是低估？
  - 从斜率场看，初值附近的解曲线呈 concave up
  - concave up 时，切线通常在曲线下方；Euler 用切线前进，容易低估
  - 结论：under-estimate，因为解曲线看起来 concave up
- 例题配置：
  - 题目：A goldfish population is modeled by $\dfrac{dN}{dt}=N\left(\dfrac{N}{6}-1\right)\left(1-\dfrac{N}{20}\right)$ with $N(0)=7$. Judging by the slope field, using Euler's method with $\Delta t=0.5$ to approximate $N(2)$ would be an under-estimate or over-estimate?
  - 已知：$\dfrac{dN}{dt}=N\left(\dfrac{N}{6}-1\right)\left(1-\dfrac{N}{20}\right)$；$N(0)=7$；$\Delta t=0.5$；斜率场显示初值附近解曲线呈 concave up
  - 目标：判断 Euler 近似 $N(2)$ 是 under-estimate 还是 over-estimate，并说明原因
  - 解题计划：从初值点沿斜率场想象解曲线 -> 判断解曲线的凹向 -> 比较 Euler 切线折线与真曲线的位置
  - 走读步骤：从 $N(0)=7$ 出发，斜率场中的解曲线向上弯，呈 concave up -> concave up 的曲线上，切线通常落在曲线下方 -> Euler 方法每一步沿当前切线走，因此折线会低于真解 -> 所以 Euler 估计 $N(2)$ 为 under-estimate
  - 易错点：看到 population 增长就直接认为高估；只看斜率正负，不看凹向；把一步切线的方向与多步折线的误差方向混为一谈
  - 最终答案：Under-estimate，因为初值附近解曲线看起来 concave up，Euler 切线折线落在真曲线下方。
