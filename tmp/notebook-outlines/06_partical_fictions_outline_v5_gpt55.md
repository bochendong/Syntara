### 5. FTC 检查：变上限积分怎样求导？
- 类型：slide
- 页面角色：definition
- 内容结构：math
- 讲解目标：能用微积分基本定理和链式法则判断积分表达式的导数。
- 页面要点：
  - FTC：$\frac{d}{dx}\left(\int_a^x f(t)\,dt\right)=f(x)$
  - 复合上限：$\frac{d}{dx}\left(\int_a^{g(x)} f(t)\,dt\right)=f(g(x))g'(x)$
  - 下限含 $x$：$\frac{d}{dx}\left(\int_{g(x)}^a f(t)\,dt\right)=-f(g(x))g'(x)$
  - 常数项如 $1,2,3$ 求导后变成 $0$。
  - 检查顺序：先看上限或下限，再代入被积函数，最后乘链式法则因子。

  - B. $y=1+\int_0^{x^2}e^{-t}\,dt$，导数为 $2xe^{-x^2}$。
  - C. $y=2+\int_{x^2}^{0}e^{-t}\,dt$，导数为 $-2xe^{-x^2}$。
  - D. $y=3+\int_0^x e^{-t^2}\,dt$，导数为 $e^{-x^2}$。
- 例题配置：
  - 题目：考虑微分方程 $\frac{dy}{dx}=-2xe^{-x^2}$。下列哪个函数是它的一个解？A. $y=1+\int_0^{-x^2}e^{-t}\,dt$；B. $y=1+\int_0^{x^2}e^{-t}\,dt$；C. $y=2+\int_{x^2}^{0}e^{-t}\,dt$；D. $y=3+\int_0^x e^{-t^2}\,dt$。
  - 已知：$\frac{dy}{dx}=-2xe^{-x^2}$；四个候选函数都以积分形式给出。
  - 目标：判断哪个候选函数的导数等于 $-2xe^{-x^2}$。
  - 解题计划：对每个候选函数求导。 -> 常数项求导为 $0$。 -> 变上限或变下限积分使用 FTC 和链式法则。 -> 与 $-2xe^{-x^2}$ 对照。
  - 走读步骤：A：$\frac{d}{dx}\int_0^{-x^2}e^{-t}\,dt=e^{x^2}(-2x)=-2xe^{x^2}$，不匹配。 -> B：$\frac{d}{dx}\int_0^{x^2}e^{-t}\,dt=e^{-x^2}(2x)=2xe^{-x^2}$，符号不匹配。 -> C：$\frac{d}{dx}\int_{x^2}^{0}e^{-t}\,dt=-e^{-x^2}(2x)=-2xe^{-x^2}$，匹配。 -> D：$\frac{d}{dx}\int_0^x e^{-t^2}\,dt=e^{-x^2}$，缺少 $-2x$。
  - 易错点：只看到 $x^2$ 就忽略上下限方向。；忘记乘上 $2x$。；把常数 $1,2,3$ 当成会影响微分方程的项。
  - 最终答案：C

  - 目标：判断 Euler 估计相对真实 $N(2)$ 是偏低还是偏高。
  - 解题计划：从初值点沿斜率场想象真实解曲线。 -> 判断该段曲线的凹凸性。 -> 比较切线折线与真实曲线的位置。 -> 给出 under-estimate 或 over-estimate。
  - 走读步骤：在 $N(0)=7$ 附近沿斜率场向右走，解曲线向上弯，判断为 concave up。 -> Euler 方法每一步都沿当前点切线走。 -> 对于 concave up 曲线，切线段通常位于真实曲线下方。 -> 所以 Euler 折线在该段低于真实解曲线。 -> 因此 $t=2$ 的 Euler 估计是 under-estimate。
  - 易错点：只看斜率是正还是负，却不判断凹凸性。；把 concave up 误判成估计偏高。；忘记 Euler 用的是当前点斜率，而不是整段平均斜率。
  - 最终答案：under-estimate，因为解曲线在该段看起来 concave up。
