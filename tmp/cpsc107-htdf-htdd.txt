目前我们学过的数据类型有：Number, String, Boolean ,Image.

Number 还能细分为 Integer 和 Natural

一定要首字母大写。




check-expect 用于测试函数是否按照预期的方式工作。它接受两个参数：第一个是你

要测试的表达式，第二个是期望的结果。如果表达式的计算结果与期望的结果相同，测

试就会通过；否则测试会失败。

Stub is a function definition that:

-   has correct function name (有正确的函数名)

-   has correct number of parameters （有正确数量的参数）

-   produces dummy result of correct type （产生一个具有正确类型的虚拟结果）



Example:

; (define (circle-area r) 0)   ; stub




Note (一般来说):

    •   Output 是 Number/Integer/Natural, 结果为 0

    •   Output 是 String, 结果为 “”

    •   Output 是 Image, 结果为 empty-image




注意一定是一个分号。

           Atomic Non-Distinct and Atomic Distinct


Atomic Non-Distinct （原子值，但没有唯一性）。也就是说，这类数据可能有多个相

同的值，无法区分。例如：整数、字符串等。

Number, String, Boolean, Image, Interval



Atomic Distinct （原子值，但有唯一性，可以明确区分）。通常，这类数据是枚举

值，例如布尔值（true 和 false）。

“Red”, false, empty …

Example：

有人要卖薛之谦的签名照，那么发出去的这个包裹，那么这个产品里面有

1. 照片

2. “薛之谦”三个大字

那么照片就是一个 Non-Distinct 的玩意（因为可能有很多不同的照片），而“薛之谦”

就是 Distinct 的玩意（因为一定是这三个字，不可能出岳云鹏）

                            One of

One of 数据类型

在 Racket 的数据设计中，One of 用于表示一个数据类型可以是多种不同类型或值的组

合。它包含两种常见形式：Enumerations 和 Itemizations。



Example：什么样的数据是 One of

我们一共有三个灯，红黄蓝，那么灯的颜色就是 one of (“red” “yellow” “blue”)



比如，我们的分数一共 5 个档，ABCDE，那么分数就是 one of (“A” “B” “C” …)



抽奖箱中有三种不同的奖品，苹果，签名照，和汽车，那么奖品就是 one of (iphone，

签名照， car …)




one of 又分为两种

1. 枚举项：指的是数据可以穷尽列出所有的可能值

2. 细分项：指的是数据是多种不同类型的结合

枚举类型(Enumerations) 表示数据的可以穷尽列出所有的可能值。

Example：


设计一个枚举型数据定义 LetterGrade 表示课程字母分数。取值仅包含下列三者之一：
"A"、"B"、"C"；

(@htdd LetterGrade)

;; LetterGrade is one of:

;; - "A"

;; - "B"

;; - "C"

;; interp. The Letter grade in the course

;; <Examples are redudant for enumerations>

(@dd-template-rules one-of

                          atomic-distinct

                          atomic-distinct

                          atomic-distinct)

(define (fn-for-letter-grade lg)

  (cond

      [(string=? lg "A") (...)]

      [(string=? lg "B") (...)]

      [(string=? lg "C") (...)]

      )

  )



Note

Normal enumerations should not use else.



Use else for large enumerations.

细分项(Itemizations) 表示数据可以是多种不同类型的组合，每个类型之间的含义可能

不同。这种类型的数据结构比枚举更复杂。

Example：


设计一个 CountDown，表示倒计时状态。他有三种形态：

     •       false —— 倒计时未开始；
     •       Natural[1, 10] —— 倒计时进行中，值表示已过去的秒数；
     •       "complete" —— 倒计时完成；




(@htdd CountDown)

;; CountDown is one of:

;; - false

;; - Natural[1, 10]

;; - "complete"

;; interp.

;;           false            means countdown is not started

;;           Natural[1, 10]   means countdown is running and how may secs has passed

;;           "complete"         means countdown is completed



(define CD1 false)

(define CD2 1)

(define CD3 10)

(define CD4 "complete")




(@dd-template-rules one-of

                          atomic-distinct

                          atomic-non-distinct

                          atomic-distinct)

                                     Compound Data

Compound Data （复杂数据）:

一个 data 含有多个内容/特性,并且这些内容都属于这个 data, 我们可以用原子数据来

组成复杂数据

o form a structure definition:

(define-struct <structure name> (<field-name1> <field-name2> ... ))



Example:

学生有名字, 学生号, 专业



那我们就可以这么写：

(define-struct student (id name major))



Question：

Compound data 和 One of 有什么区别？



One of 指的是，我是其中之一，要么是，要么是的关系，但是你不可以说，一个学生要

么是名字, 要么是学生号, 要么是专业。Compound data 表示我同时拥有



使用方式：
(define SD1 (make-student 101 "Andy" "CS"))

(define SD2 (make-student 301 "Oscar" "Math"))

(student-name SD1)

(student-id SD1)
