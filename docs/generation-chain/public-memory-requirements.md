# 公共记忆写入要求

公共记忆直接影响之后的聊天、答疑、出题和 notebook 续写质量。它不是生成完成后的备注，而是把课程里模型容易瞎猜、互联网上又不容易查到的知识，注入到后续学习链路里。

## 一、公共记忆优先写课程私有知识

必须包括：

- 老师实际讲了什么：本节主线、核心概念、关键术语、老师强调的判断方式。
- 老师要求的格式：证明格式、代码格式、答题格式、模板结构、命名习惯、提交要求。
- 老师给出的标准步骤：证明怎么展开、代码怎么组织、计算怎么分层、题目怎么检查。
- 本课程特有的约束：哪些方法可用，哪些常见方法不要用，哪些符号或术语按老师的说法来。

为什么要包括：

这类知识通常不在公共互联网上，或者即使网上有类似内容，也不一定符合这门课老师的要求。模型最容易在这里用通用经验补空，导致回答看似合理但不符合课程。

## 二、通用知识少写，避免污染记忆

不优先写：

- 教科书里稳定存在的通用定义。
- 模型通常能准确处理的标准计算技巧。
- 和老师要求无关的背景百科。
- 一次性页面排版、临时标题、生成过程里的内部决策。
- 大段原文、完整题库或整页讲稿。

为什么要限制：

公共记忆不是资料仓库。写太多通用知识会稀释真正重要的课程约束，也会让后续聊天被不必要的信息带偏。模型本来就能高准确率完成的内容，不需要用记忆重复塞一遍。

## 三、记忆密度取决于模型是否容易瞎猜

高优先级写入：

- 课程有老师自定义模板、专用流程或评分格式。
- 课程内容依赖课堂材料，而不是公开教材常识。
- 老师的写法和互联网上常见写法不同。
- 一旦答错，会直接影响学生作业、考试或代码风格。

低优先级写入：

- 内容属于通用数学、通用编程或通用概念解释。
- 模型只需要知道当前 notebook 的主题，不需要长期记住细节。
- 细节只对当前页面有用，之后聊天不会复用。

为什么要分级：

公共记忆的价值在于补模型盲区，不是复制整门课。越是老师私有、课程私有、格式私有的知识，越值得写；越是通用、稳定、模型已擅长的知识，越应该少写。

## 四、每条记忆要可复用、可验证

必须包括：

- 适用范围：课程、单元、主题或材料范围。
- 知识类型：概念主线、证明格式、代码模板、计算步骤、易错点或老师偏好。
- 具体规则：后续生成或答疑时应该怎么做。
- 来源依据：来自原始 PDF、课堂材料、用户要求或已确认 notebook。
- 限制条件：只适用于某门课、某周内容或某类题时，要写清楚。

为什么要包括：

后续聊天需要知道这条记忆什么时候该用、什么时候不该用。没有范围和来源的记忆，会让模型把某门课的特殊格式误套到别的课上。

## 五、公共记忆应进入主生成链路

必须包括：

- 读取原始材料后，先提取可复用的课程约束。
- 大纲或页面规划确认后，写入本次 notebook 的主线、页面索引和关键学习动作。
- 对老师私有格式、证明格式、代码格式和评分偏好，写成稳定规则。
- 生成完成后，补充最终确认的例题、易错点、术语和适用范围。

为什么要包括：

公共记忆如果只在最后随手写，很容易漏掉真正影响质量的课程约束。它应该和内容生成、页面规划、讲解稿生成在同一条主链路里，保证后续页面和后续聊天都能用到。

## 六、失败判定

出现以下情况，公共记忆不合格：

- 只写了 notebook 生成了哪些页面，没有写老师讲了什么。
- 只写通用概念，没有写课程特有格式或老师要求。
- 把模型本来就会的通用知识塞满记忆。
- 没有区分“老师要求”和“通用推荐”。
- 没有记录适用范围，导致别的课程也会误用。
- 凭空补写课程模板、证明格式或代码格式，没有原始材料依据。
- 忽略低互联网可得性的知识，导致后续聊天继续靠模型猜。
