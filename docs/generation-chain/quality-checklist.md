# Notebook 质量检查清单

生成结束后按这份清单检查。任何一项不合格，都应该回到对应阶段修复，而不是只接受“已经生成完”。

## 一、整本主线

- 有一句话主线，不只是主题名。
- 有贯穿整本的中心问题。
- 有引入页，先建立问题、背景或学习动机，不直接进入结论。
- 页面顺序能形成推进：引入、路线、核心概念、例题/应用、总结。
- 最后一页能回扣中心问题，而不是只有术语列表。
- 课程上下文、课程代码、课程用途和用户需求没有互相冲突。

## 二、页面规划

- 每页只有一个主要教学动作。
- 每页都有 fromPrevious、currentJob、toNext 这类承接关系。
- 页数符合用户选择的篇幅。
- 少页 notebook 没有被压成密集讲义。
- 多页 notebook 没有重复讲同一个点。
- quiz 不出现在真正教学开始前。

## 三、例题与证明

- 已读取原始 PDF，并提取老师给出的标准阶梯步骤。
- 原始材料里的题目、定义、公式、代码、图示或表格被准确保留。
- 每个关键步骤都有判断依据，而不只是中间结果。
- 内容顺序能看出老师原本的教学阶梯。
- 需要做题/证明/代码训练时，有足够数量的完整例题。
- 每组完整例题有题目、已知、目标、策略、步骤、答案或检查。
- 每一步说明依据，不只写结果。
- 有常见误区或检查点。
- 例题和课程前置知识匹配，不超纲。

## 四、图片页

- 每个可遮罩学习组件都有 4 个角标，角标能恢复出组件边界。
- marker 颜色只出现在角标上，没有被普通文字、箭头、边框或装饰误用。
- 每页参与遮罩的学习组件不超过 6 个；超过就拆页或合并。
- 画面是 16:9 满版，不是画布中间的小卡片。
- 标题、公式、代码和关键文字在缩略图里仍可读。
- 学生可见文字使用目标语言。
- 没有“教学目标”“本页主线”“讲解重点”“QA checklist”等教案标签。
- 没有浏览器 UI、营销卡片、占位文字、水印或无关装饰。
- 每页视觉风格统一，但页面结构不机械重复。
- 公式、代码、题目原文准确。
- 源图、原题、公式、代码被准确迁移，不能为了画面效果改写内容。

## 五、遮罩与讲解

- 每页有 1-6 个真正可讲的 focus 区域。
- focus 区域对应学习组件，不框装饰。
- 每个 focus 区域都有遮罩预览图；预览图能看出全页被压暗，焦点学习组件被保留。
- metadata 里能从 focus region 追溯到对应遮罩预览图。
- 讲解先聚焦再说话。
- focus 和 speech 对得上，讲哪里就框哪里。
- speech 数量足够解释页面，不只是三两句摘要。
- 每段 speech 只推进一个观察、判断、步骤或提醒。
- 一个 focus 可以支撑一小段连续讲解，不被机械切成一句一框。
- 旁白不逐字朗读页面，而是解释判断、依据、误区、检查和下一步。
- 前后页讲解有承接，结尾能自然交给下一页。
- 公式讲意思、用途和判断方法，不硬读整行公式。
- speech 文本适合语音朗读，没有 `2^n`、`log_2`、raw math、LaTeX、难读符号、讲师备注或生成提示词。

## 六、完成状态

- 已保存 stage、scenes 和 outlines。
- 失败页被记录，不能静默丢页。
- 成功生成的页面能按顺序进入课堂。
- 用户看到的是完成后的页面 grid 和进入课堂入口，而不是又回到创建状态。

## 七、公共记忆

- 公共记忆写入最终主线、页面索引、例题与易错点。
- 公共记忆记录老师实际讲了什么，而不只是页面生成结果。
- 课程指定的证明格式、代码格式、答题格式或模板结构已写入。
- 原始材料里的标准步骤和老师偏好已写入。
- 只写课程私有、老师私有、低互联网可得性的高价值知识。
- 通用定义、标准计算技巧、背景百科没有被大量写入。
- 每条记忆有适用范围，避免误套到其他课程。
- 没有凭空补写课程模板、证明格式或代码格式。
