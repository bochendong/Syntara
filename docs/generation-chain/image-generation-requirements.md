# 图像生成要求

图像生成只看四件事：风格、内容、不允许出现的东西、必须符合的图片规范。四角标识属于图片规范，而且是最重要的规范。

## 一、风格

- 风格必须服从本次 notebook 的课程和用户选择，可以是手写板书、线稿、水彩、卡通、极简或其他明确方向。
- 整本 notebook 要有统一气质，同一本书的页面不能像不同模板拼在一起。
- 风格不能压过教学内容。标题、公式、代码、题目和图示永远比装饰更重要。
- 页面应该像课堂板书或讲台屏幕，不像宣传海报、网页截图、UI 仪表盘或商业 PPT 模板。
- 可以有纸纹、黑板、白板、手写感、插画辅助，但不能遮挡或挤压学习组件。

## 二、内容

- 每页只表达一个主要教学动作。
- 学生第一眼要知道先看哪里，第二眼要知道要判断什么，最后知道这一页带走什么。
- 学生可见文字必须使用目标语言；数学符号、变量名、代码标识符和课程代码可以按原文保留。
- 页面文字要短、准、大，缩略图里至少能读出标题和核心内容。
- 公式、定义、定理、代码、题目原文、图表标签必须准确，不能为了画面效果改写。
- 普通正文页控制在 2-3 个主要学习区域：入口问题、核心图/公式/代码/例题、底部收束。
- 复杂证明、长代码、长计算和多步骤例题要拆页，不能硬塞成密集小字讲义。

## 三、不允许出现的东西

- 不允许出现教案或 prompt 标签：`教学目标`、`本页主线`、`讲解重点`、`可迁移动作`、`Teacher move`、`Page role`、`QA checklist`。
- 不允许出现浏览器外壳、手机外壳、软件面板、网页 UI、营销海报、水印、占位框或“AI 生成”字样。
- 不允许把页面画成大画布中间的小卡片、小纸张、小白板或小幻灯片。
- 不允许使用乱码、伪公式、伪代码、无意义占位文字或省略号凑内容。
- 不允许把 marker 颜色用在普通文字、箭头、边框、装饰色块或图表线条上。
- 不允许额外生成类似 marker 的纯色小方块。

## 四、必须符合的图片规范

### 1. 基础格式

- 图片必须是 16:9 横向整页图。
- 画面必须满版，不留无意义外框、白边、黑边或嵌套画布。
- 主要内容必须清晰可读，不能模糊、过暗、过密或被装饰遮挡。

### 2. 四角标识

四角标识是给每个可讲解学习组件加的 4 个实心纯色小方块，用来让系统从整页位图里恢复组件边界。它不是 L 形角线、括号、边框、连线或手绘装饰，4 个小方块之间不能被线条连接。

- 每个参与遮罩的学习组件必须正好 4 个角标。
- 4 个角标分别放在组件外接矩形的左上、右上、左下、右下。
- 同一个组件的 4 个角标必须使用同一种专属 marker 颜色。
- marker 颜色只能使用项目固定颜色池：`#ff0000`、`#00ff00`、`#0048ff`、`#00ffff`、`#ff00ff`、`#ffff00`。
- 角标要贴近组件边界，但不能碰到文字、公式、线条、箭头或填充区域。
- 角标只负责定位，不负责视觉分组；不要用直线、框线、括号或底色把 4 个角标连成一个区域框。
- 角标附近要留干净背景，方便后处理擦除。
- 每页最多 6 个参与遮罩的学习组件；超过就合并组件或拆页。
- 一个学习组件必须是紧凑、自包含的区域，不能被拆成远距离碎片。

四角标识的目的不是给学生看，而是给后处理定位。系统会用它恢复 focus region，再生成遮罩、spotlight、laser 和讲解动作，最后把 marker 擦掉，输出学生看到的 clean image。

生成链路必须保存可检查的遮罩预览：每个参与遮罩的学习组件至少有一张 dim 全页、保留焦点区域的预览图，并在 metadata 里能从 region 追溯到对应预览图。只保存 clean image 或 source marker image 不够，因为那只能证明 recover，不能证明遮罩区域真的覆盖了学生应该看的内容。

### 3. 失败判定

出现以下任一情况，图片就不合格：

- 缺角标、角标数量不对、角标颜色错用或出现额外 marker-like 色块。
- 学习组件边界无法从四角标识恢复。
- 没有导出遮罩预览，或遮罩预览框到装饰、空白、半截公式、半截代码。
- 文字太小、模糊、乱码或语言混杂。
- 公式、代码、题目被改错。
- 页面太密，应该拆页却被硬塞进一张图。
- 页面像装饰插图或宣传页，不能支撑逐步讲解。

失败时优先修改 `componentPlans`、页面规划或图片 prompt plan，不要只要求模型“重画得好看一点”。
